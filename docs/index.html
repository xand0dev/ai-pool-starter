Не прив’язуйся до однієї моделі

Один інструмент — увесь пул моделей. Контекст проєкту — у репозиторії, а не в чаті. Закінчився ліміт → /models → інша модель продовжує з того самого місця.

⬇ Завантажити шаблон (ZIP) Репозиторій на GitHub ↗
Сетап за 10 хвилин_×

1Встановити OpenCode

curl -fsSL https://opencode.ai/install | bash

Або brew install anomalyco/tap/opencode, або npm install -g opencode-ai (зручно на Windows).

2Зібрати свій пул: /connect

Запустіть opencode, наберіть /connect і підключіть те, що у вас уже є:

Звідки модельЩо вибратиВартість
Підписка ChatGPTOpenAI → ChatGPT Plus/Proу межах підписки
Підписка CopilotGitHub Copilotу межах плану
БезкоштовноOpenCode Zen → моделі Freeперелік змінюється
Свій ключ (BYOK)Anthropic, Google, DeepSeek…за тарифом провайдера
ЛокальноLM Studio / Ollama (див. README)ваш комп’ютер
API-ключ — це секрет. Не вставляйте його в код, у чат і не показуйте на екрані.

3Відкрити поруч із кодом у VS Code

Запустіть opencode у терміналі VS Code — інтеграція поставиться сама. Cmd+Esc (Windows/Linux: Ctrl+Esc) відкриває OpenCode поруч із кодом; виділений фрагмент автоматично йде в контекст.

4Додати контекст у свій проєкт

Скопіюйте файли шаблону в корінь свого репозиторію (або завантажте ZIP вище):

AGENTS.mdПостійні правила. Заповнити один раз — OpenCode читає сам.
відкрити ↗
PROJECT_CONTEXT.mdПоточний стан і план по кроках.
відкрити ↗
HANDOFF.mdДе зупинились і що робити далі.
відкрити ↗
opencode.jsonПідключає PROJECT_CONTEXT і HANDOFF до кожної моделі.
відкрити ↗
.opencode/commands/Команди /handoff і /resume.
відкрити ↗
Щоденний цикл_×
  1. Працюєте з будь-якою моделлю. Tab перемикає Plan (правки лише з дозволу) ↔ Build.
  2. Закінчився ліміт → /models → інша модель продовжує в тому самому чаті.
  3. Перерва або нова сесія → /handoff — оновлює HANDOFF.md.
  4. Нова сесія → /new → /resume — будь-яка модель підхоплює роботу з файлів.
  5. Перевіряйте результат самі: агент може написати «працює», коли не працює.
