# AI Pool Starter

**Не прив’язуйся до однієї моделі.** Один інструмент — увесь пул моделей. Контекст проєкту — у репозиторії, а не в чаті.

Закінчився ліміт → `/models` → інша модель продовжує з того самого місця.

## Сетап за 10 хвилин

### 1. Встановити OpenCode

```bash
curl -fsSL https://opencode.ai/install | bash
```

Або `brew install anomalyco/tap/opencode`, або `npm install -g opencode-ai` (зручно на Windows). Документація: https://opencode.ai/docs

### 2. Зібрати пул моделей

Запустіть `opencode` і наберіть `/connect`. Підключайте те, що у вас уже є:

| Звідки модель | Що вибрати в `/connect` | Вартість |
|---|---|---|
| Ваша підписка ChatGPT | OpenAI → ChatGPT Plus/Pro | у межах підписки |
| Ваша підписка Copilot | GitHub Copilot | у межах плану Copilot |
| Безкоштовно | OpenCode Zen → моделі з позначкою **Free** | безкоштовно, перелік змінюється |
| Свій ключ (BYOK) | Anthropic, Google, DeepSeek… | за тарифом провайдера |
| Локально | див. нижче (LM Studio / Ollama) | ваш комп’ютер |

Перевірте пул: `/models`.

> API-ключ — це секрет. Не вставляйте його в код, у чат і не показуйте на екрані.

### 3. Відкрити поруч із кодом у VS Code

Запустіть `opencode` у терміналі VS Code: інтеграція поставиться сама.
`Cmd+Esc` (Windows/Linux: `Ctrl+Esc`) — OpenCode поруч із кодом. Виділений фрагмент автоматично потрапляє в контекст.

### 4. Додати контекст у свій проєкт

Скопіюйте в корінь свого репозиторію:

```
AGENTS.md            ← постійні правила (заповнити один раз)
PROJECT_CONTEXT.md   ← поточний стан і план
HANDOFF.md           ← де зупинились і що далі
opencode.json        ← підключає PROJECT_CONTEXT і HANDOFF до кожної моделі
.opencode/commands/  ← команди /handoff і /resume
```

OpenCode читає `AGENTS.md` сам; `opencode.json` додає до кожної сесії ще два файли.

## Щоденний цикл

1. Працюєте з будь-якою моделлю (Tab перемикає **Plan** → **Build**).
2. Закінчився ліміт → `/models` → інша модель продовжує **в тому самому чаті**.
3. Перед перервою або новою сесією → `/handoff` (оновлює `HANDOFF.md`).
4. Нова сесія → `/new` → `/resume`: будь-яка модель підхоплює роботу з файлів.
5. Перевіряйте результат самі — агент може написати «працює», коли не працює.

## Локальна модель (необов’язково)

Додайте до `opencode.json` (назву моделі замініть на свою):

```json
"provider": {
  "lmstudio": {
    "npm": "@ai-sdk/openai-compatible",
    "name": "LM Studio (local)",
    "options": { "baseURL": "http://127.0.0.1:1234/v1" },
    "models": { "qwen2.5-coder-7b-instruct": { "name": "Qwen 2.5 Coder 7B (local)" } }
  }
}
```

Для Ollama — те саме з `"baseURL": "http://localhost:11434/v1"`.

## Чому файли, а не «пам’ять чату»

| | Prompt cache | Project Context (ці файли) |
|---|---|---|
| Навіщо | дешевше й швидше повторювати той самий запит | зберегти стан роботи |
| Де живе | у провайдера, з часом життя | у вашому репозиторії, під git |
| Переживає зміну моделі | ні | так |
